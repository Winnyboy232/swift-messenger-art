# Swift Messenger

A minimalist, ultra-modern mobile messaging app named "Swifty." Create a beautiful default dark theme. Add a unique, stylized digital art logo in the top center of the splash screen and app headers that depicts a "Common swift bird (Apus apus)" shown in a side view during rapid flight. Give the swift bird a blend of deep electric blue and subtle glowing purple colors to make it stand out. This logo should be small but prominent, using a vibrant color palette against the dark background. Create a clean main app navigation with a bottom navigation bar containing 4 essential, labeled tabs: "Chats," "Status," "Contacts," and "Settings." The "Chats" tab should initially show a placeholder list with a few empty chat entries, and the other tabs should have simple placeholder content.
